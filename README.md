# CivicPulse

An explainable civic dashboard for identifying repeated Boston 311 service patterns and supporting equitable human review.

## Hackachusetts 2026 — Civic Action

CivicPulse is built for the Hackachusetts 2026 Civic Action track, focusing on transparent, community-centered tools that surface patterns in municipal service data and empower reviewers to act equitably.
